# FOUNDER.

Независимый русскоязычный бизнес-журнал. Истории предпринимателей, разборы деловых ошибок, книжные конспекты и один небольшой шаг на сегодня.

На обложке первого выпуска история Patagonia. В архиве можно искать материалы и отбирать их по теме. Закладки и записи трекера хранятся в браузере. В разделе «Точка опоры» и книжных конспектах можно скачать вертикальную карточку мысли в PNG.

## Локальный запуск

Из корня проекта выполните:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальную версию](http://127.0.0.1:8000/). Для запуска достаточно Python 3. Сборка и установка пакетов не требуются. После первого открытия по HTTPS или на localhost сервис-воркер сохраняет материалы, изображения и шрифты для чтения офлайн. Внешние публикации и ролики открываются у источников.

## Контент и выпуск

- Истории, книги, источники и заметки редакции находятся в `js/content.js`.
- Реальные заголовки и выпуски хранятся в `data/news.json` и `data/videos.json`. Команда `python scripts/update_feeds.py` обновляет локальные копии.
- GitHub Actions публикует сайт при изменениях в `main` и по расписанию каждые шесть часов. Перед публикацией он обновляет ленты. Если источник временно недоступен, сохраняются его материалы из последней доступной копии. Для GitHub Pages выбран источник GitHub Actions.
- В публикацию входят HTML, манифест, сервис-воркер и каталоги `assets`, `css`, `js`, `data`.
